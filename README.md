# 云小助 · 原型预览

静态预览站，内容来自内部设计仓库 `sucai-ku` 的 `prototype/`，**只读镜像**，不是源码仓库。

- 顶部按钮 / 快捷键 `1`·`2` / URL `#app`·`#real` 切换两个视图：
  - `#app` 销售端 App（Android · Material Design 3）
  - `#real` 线上后台复刻
- 与源仓库的差异（仅为公网分发所做的改动）：
  1. 移除了右上角「历史版本」切换器（其数据是内部提交信息索引）；
  2. 加了 `noindex`，不进入搜索引擎；
  3. 加了 `.nojekyll`，否则下划线开头的 `_online-admin.js` 会被 Jekyll 过滤掉。

要改内容请改源仓库并重新导出，不要直接改这里。
